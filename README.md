# Orbit

用一個圓環看收支的記帳 App，在 iPhone 上以網頁 App（PWA）的形式使用。

目前進度：**M1 記帳功能完成（M1a 新增與儲存、M1b 編輯／刪除／復原、M1c 備份匯出與匯入）**。
帳目存在這支手機的瀏覽器裡，重新整理或關掉再開仍然在；也可以匯出備份檔，換手機或清除資料後匯入還原。

## 在 iPhone 上使用

1. 用 Safari 開啟網站網址。
2. 點下方的「分享」按鈕 → **加入主畫面**。
3. 之後從主畫面的 Orbit 圖示開啟，會以全螢幕、像一般 App 的方式執行。

## 記一筆帳

1. 點畫面下方的「＋」。
2. 在視窗上方切換「支出」或「收入」；右上角可選日期（‹ › 前後一天，或點日期選其他天；不能記未來的帳）。
3. 用內建的數字鍵盤輸入金額（最多 8 位數；`00` 可以一次補兩個零）。
4. **左右滑動**類別卡片換類別（也可以直接點旁邊那張）；預設停在第一個類別。再在「具體事項」欄自己輸入內容（選填，最多 40 字），例如滑到「學習」後輸入「書本費」。
   欄位的提示文字會依類別換成範例。
5. 最後一張卡片是「＋ 新增類別」，點它可以自訂類別（名稱最多 8 字、挑一個顏色，每種收支最多 12 個）。
   自訂類別被選中時，下方會出現「編輯此類別」可改名、換色或刪除；刪除後舊帳目會歸到灰色的「未分類」，金額不會消失。
   停在「新增類別」那張時不能儲存。
6. 按「儲存」。

明細列表裡，**主標題是類別，副標題是你輸入的具體事項**（週／月／年檢視時，副標題前面會加上日期）。
存好後，畫面會回到你剛記的那一天，並切到對應的圓環。

## 帳戶、轉帳與資產

- **帳戶**分三大類：現金、信用卡、存款，每一類底下可以有多個自訂的子帳戶（例如「郵局存款」）。第一次使用時會先建立「錢包」「信用卡」「銀行存款」三個，可以改名。
- **記帳時選帳戶**：類別下面多一排帳戶，一樣左右滑動選擇。支出可以用現金、信用卡或存款；收入只能存入現金或存款。
  預設是同一種收支上次用的帳戶；最後一張「＋ 新增帳戶」可以當場新增。
- **轉帳**：記帳視窗上方「支出／收入／轉帳」選「轉帳」，用兩排滑動選「轉出」與「轉入」帳戶。
  例如現金 3,000 轉入郵局存款：資產頁的現金減少 3,000、郵局存款增加 3,000。轉帳不計入支出或收入圓環。
  繳信用卡費就是「存款 → 信用卡」的轉帳。
- **資產頁**（底部左邊的圓餅圖按鈕）：最上面是「資產」與淨資產（現金＋存款－信用卡欠款），下面是三大類；
  大類名稱靠左、合計靠右，子帳戶名稱靠左、金額靠右。現金與存款是綠色，信用卡是紅色（已刷未繳），下面小字是自訂的額度上限與可用額度。
  點子帳戶可以改名、改期初金額與額度上限，或刪除（帳目會保留，只是不再計入）；每一類下方可以新增帳戶。從上往下滑關閉。
- 帳戶功能推出前記的舊帳目沒有帳戶，不會影響任何帳戶的金額。

## 搜尋（底部右邊的放大鏡）

- 最上方輸入要找的內容（具體事項或類別名稱，例如「午餐」）；之後點它可以重新輸入。
- 下面的卡片顯示這筆查詢在「日／週月／年」範圍內的總額（以主畫面目前看的日期為準），左右滑動切換範圍；支出紅色、收入綠色。
- 再下面是範圍內所有符合的紀錄，可以上下捲動。從上往下滑關閉，下次打開會保留上次的查詢。

## 編輯、刪除與復原

- **編輯**：點明細列表的任一筆，開啟的視窗會預先填好內容，改完按「儲存變更」。
- **刪除**：在編輯視窗按「刪除」，或在明細上**向左滑**露出紅色「刪除」再點一下。
- **復原**：刪除後 5 秒內，畫面下方會出現「復原」按鈕。只能復原最近一次刪除；過了 5 秒或又出現別的提示，就救不回來了。
- 示範資料不能編輯或刪除。

## 備份與匯入（設定頁）

- **匯出備份**：產生 `orbit-backup-日期.json`。在 iPhone 上會跳出系統的分享選單，請選「**儲存到檔案**」才算完成。
  （不能開分享選單的瀏覽器會改成直接下載。）
- **匯出 CSV**：給試算表看的檔案（日期、收支、類別、具體事項、金額）；不能用來匯入。
- **匯入備份**：選擇備份檔後會先顯示摘要（新增幾筆、更新幾筆、略過幾筆），按「確認匯入」才會寫入。
  - 匯入**不會刪除**手機上現有的帳目。
  - 編號相同、內容不同時，以「較晚修改」的那一份為準。
  - 格式不正確的帳目會被略過並告知；不是 Orbit 的備份檔會被拒絕。
- 設定頁會顯示上次備份的時間與目前的帳目筆數。
- 備份檔現在也包含你的自訂類別（備份格式版本 2）；版本 1 的舊備份仍可匯入。

## 顯示方式：圓環／行星（設定頁）

- **行星**（預設）：中央的太陽顯示總額，每個類別是一顆行星。行星越大代表金額越多，占比越大的越靠近太陽；內圈轉得快、外圈轉得慢。
  切換支出／收入或層級時，行星會由大到小依序從太陽飛出。點一顆行星，中央顯示它的名稱、金額與百分比。
  開著視窗時行星會暫停轉動以省電；開啟系統的「減少動態效果」時完全靜止。
- **圓環**：從正上方順時針，占比由大到小，看比例最清楚。
- 兩種方式的資料、手勢完全相同，隨時可以切換。
- 行星模式切換支出／收入時是「日食」：月亮滑過來遮住太陽，太陽換色，月亮移開後露出新的行星。
- 雙指縮放時，圓環或星系會跟著手指即時縮放；放開時縮放幅度夠大才換層級，不夠就彈回原狀。
- 行星模式換層級時有轉場：看更長的期間（日→週→月→年）時，整個星系先收進太陽，再從太陽向外散開成新的資料；
  看更短的期間時，行星向外飛散，新的行星再從外圍落回軌道。

## 選擇日期（點頂部的日期）

- 上方切換「日／週／月／年」，會立刻套用（日期不變），視窗不會關。
- 下方依層級顯示月曆、12 個月份或年份；點一格就跳到那裡並關閉。有帳目的日子／月份／年份下方有小圓點。
- 不能選未來；「回到今天」一鍵回到今天。

## 紅綠色盲友善模式（設定頁）

開啟後，支出改用藍色系、收入改用黃色系；圓環、金額文字、類別顏色都會一起換。顏色只影響外觀，不影響帳目資料。

## 操作方式

| 位置 | 操作 | 效果 |
| --- | --- | --- |
| 圓環 | 向右滑 / 向左滑 | 往過去 / 往較近一個期間（最近只到今天） |
| 圓環 | 上滑或下滑 | 切換支出圓環與收入圓環（圓環會從正上方開始順時針填滿，由占比大的類別畫到小的） |
| 圓環 | 雙指縮小 / 放大 | 日 → 週 → 月 → 年 / 反向 |
| 圓環色塊 | 點一下 | 中央顯示該類別的名稱、金額與百分比 |
| 圓環下方圓點 | 左右滑動或點圓點 | 切換日／週／月／年 |
| 明細列表 | 上下捲動 | 只捲動列表，不會切換圓環 |
| 明細列表 | 點一下 / 向左滑 | 編輯 / 露出刪除 |
| 左上角 | 點設定圖示 | 開關示範資料、查看資料儲存狀態 |
| 新增視窗 | 往下滑、點背景、點 ✕ | 關閉視窗 |

在電腦上測試：← → 換日期，↑ ↓ 切換圓環，`-` `+` 換層級；新增視窗開著時可直接用鍵盤輸入數字。

## 關於你的資料

- 帳目只存在這支手機的瀏覽器（IndexedDB）裡，不會傳到任何伺服器，GitHub 上也沒有你的帳目。
- **清除 Safari 的網站資料、刪除主畫面 App 或換手機，帳目都會消失。** 請定期到「設定」匯出備份，並確認備份檔真的存進「檔案」App。
- 備份檔沒有加密，裡面是你的完整帳目，請放在你信任的地方，不要傳到公開的地方。
- 「示範資料」只是畫面上的假帳目，預設關閉，不會存進帳本。

## 帳目的資料格式

```
{ id, type: 'expense' | 'income', catId, accountId?, amount, date: 'YYYY-MM-DD', note, createdAt, updatedAt? }
{ id, type: 'transfer', fromId, toId, amount, date, note, createdAt, updatedAt? }      ← 轉帳
```

`note` 就是畫面上的「具體事項」（欄位名稱沿用，舊帳目不需要轉換）；`updatedAt` 只有編輯過的帳目才有。
備份檔格式：`{ app: 'orbit', version: 3, exportedAt, count, categories, accounts, entries }`（版本 1、2 的舊備份仍可匯入）。
帳戶格式：`{ id, kind: 'cash'|'credit'|'bank', name, opening, limit? }`，存在資料庫 meta 的 `accounts`。
自訂類別存在資料庫的 `meta` 區（資料庫版本 2，舊資料會自動升級、不會遺失）。

金額是整數（新台幣元）；日期用字串存，避免時區造成差一天。

## 更新後要注意

改了任何檔案，記得把 `sw.js` 裡的 `CACHE` 版本號加一（例如 `orbit-v10` → `orbit-v11`），
新增了檔案也要加進 `FILES` 清單，否則已經安裝的手機可能還會看到舊版本或缺檔案。
