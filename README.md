# Orbit

用一個圓環看收支的記帳 App，在 iPhone 上以網頁 App（PWA）的形式使用。

目前進度：**M0 首頁畫面預覽**。圓環、日期標籤、層級圓點、明細列表與手勢都已經可以操作，
但資料是示範資料；真正的記帳功能（新增、編輯、儲存）會在下一個階段加入。

## 在 iPhone 上使用

1. 用 Safari 開啟網站網址。
2. 點下方的「分享」按鈕 → **加入主畫面**。
3. 之後從主畫面的 Orbit 圖示開啟，會以全螢幕、像一般 App 的方式執行。

## 操作方式

| 位置 | 操作 | 效果 |
| --- | --- | --- |
| 圓環 | 向右滑 / 向左滑 | 往過去 / 往較近一個期間（最近只到今天） |
| 圓環 | 上滑或下滑 | 切換支出圓環與收入圓環 |
| 圓環 | 雙指縮小 / 放大 | 日 → 週 → 月 → 年 / 反向 |
| 圓環色塊 | 點一下 | 中央顯示該類別的名稱、金額與百分比 |
| 圓環下方圓點 | 左右滑動或點圓點 | 切換日／週／月／年 |
| 明細列表 | 上下捲動 | 只捲動列表，不會切換圓環 |

在電腦上測試：← → 換日期，↑ ↓ 切換圓環，`-` `+` 換層級。

## 檔案結構

```
index.html           頁面骨架
css/style.css        樣式（含深色模式）
js/main.js           主程式：狀態、畫面更新、操作
js/dateutil.js       日期與期間計算（週一起算、標籤格式）
js/ring.js           圓環繪製（SVG）
js/gestures.js       滑動與雙指縮放的判斷
js/sample.js         示範資料（M1 之後會換成真實資料）
sw.js                Service Worker（離線可用）
manifest.webmanifest 加到主畫面所需的設定
icons/               App 圖示
tests/               日期計算的單元測試
```

## 更新後要注意

改了任何檔案，記得把 `sw.js` 裡的 `CACHE` 版本號加一（例如 `orbit-v3` → `orbit-v4`），
否則已經安裝的手機可能還會看到舊版本。
