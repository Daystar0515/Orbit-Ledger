## 你的錢，是一個小小的太陽系

打開 Orbit，畫面中央是一顆**太陽**，上面寫著這段期間的總額。
每個消費類別都是一顆**行星**，沿著自己的**軌道**慢慢公轉：

- **行星越大，花得越多**；占比越大的類別，軌道越靠近太陽。
- 內圈轉得快、外圈轉得慢，跟真正的太陽系一樣（克卜勒定律）。
- 點一顆行星，太陽會告訴你它的名稱、金額與占比，下方明細也會把這個類別的紀錄排到最前面。
- 明細依你正在看的宇宙排序：支出宇宙時支出在前、收入在後；收入宇宙時反過來；轉帳排最後。

時間也是宇宙的一部分：

| 你做的事 | 宇宙的反應 |
| --- | --- |
| 雙指**縮小**，從「日」看到「週、月、年」 | 整個星系被吸進太陽，再從中心向外散開成新的星系 |
| 雙指**放大**，回到較短的期間 | 行星向外飛散，新的行星從外圍落回軌道 |
| 雙指縮放的過程中 | 星系跟著你的手指即時縮放；放開時幅度不夠就彈回 |
| **上下滑**，切換支出與收入 | 日食：月亮滑過來遮住太陽，太陽換色，露出另一個星系 |
| **左右滑**，往前或往後一天／週／月／年 | 整個星系滑入下一段時間 |
| 打開 App | 行星依大小順序，從太陽飛出各就各位 |

> 想省電，或想一眼看清楚比例？到「設定 → 顯示方式」切換成**省電圓環**：
> 沒有持續的動畫，圓環從正上方順時針、由大到小填滿。資料與手勢完全相同，隨時可以切回宇宙。

## 功能

**記帳**
- 支出、收入、轉帳三種；金額用內建數字鍵盤輸入（新台幣整數）。
- 類別左右滑動選擇，選好後輸入具體事項，例如「學習 → 書本費」。可以自訂類別與顏色。
- 每筆帳都會記下帳戶：支出可用現金、信用卡或存款；收入存入現金或存款。
- 類別與帳戶的卡片可以**無限循環滑動**，滑到最後一張會接回第一張。
- 金額右邊的「**手續費**」按鈕可以加上手續費、運費、服務費、稅金、小費，或扣掉優惠折扣、折價券、點數折抵；
  收入可以扣掉手續費、代扣稅金或加上加給。總金額會自動算好，明細上會顯示原價與每一項調整。
  轉帳的手續費會從轉出帳戶多扣，轉入的金額不變。
- 點明細可以編輯，向左滑可以刪除，刪除後 5 秒內可以復原。
- 可以**預先記未來的收支**（最遠兩年後），例如下個月的房租。未來的帳目在明細上標示「預計」，
  到那天之前不會計入資產；往後滑最遠可以滑到最後一筆預先記的帳目那天。

**資產**（底部左邊的圓餅圖）
- 現金、信用卡、存款三大類，每類可以有多個帳戶，例如「郵局存款」。
- 現金與存款以綠色顯示餘額，信用卡以紅色顯示已刷未繳，並標示自訂的額度上限與可用額度。
- 最上方是淨資產（現金＋存款－信用卡欠款）。
- 轉帳讓錢在帳戶間移動：提款是「存款 → 現金」，繳卡費是「存款 → 信用卡」。
- 信用卡可以設定**結帳日**與**繳款日**（每月幾號；遇到較短的月份自動改成月底），資產頁會顯示下次是哪天、還有幾天。
- 存款可以選擇**設定利率**：年利率、計息日、發息日與發息頻率（每月／每季／每半年／每年），資產頁會顯示估算的年息。

**信用卡與存款提醒**
- 每張信用卡、每個設定了利率的存款帳戶都可以各自開關提醒：信用卡提醒結帳日／繳款日，存款提醒計息日／發息日，
  時間可選**當天、前一天、前一週**（可複選）。
- 打開 Orbit 時，如果今天該提醒，畫面下方會出現提醒，按「查看」可以打開資產頁；同一個提醒一天只出現一次。
- 想在 Orbit **沒開著的時候**也收到通知，請在信用卡設定裡按「**加入 iPhone 行事曆**」：
  會產生每月重複、早上 9 點提醒的行事曆事件，由 iPhone 行事曆負責通知（iPhone 行事曆一個事件最多保留 2 個提醒）。
  這是因為 Orbit 是沒有伺服器的網頁 App，無法自己在背景推播。

**搜尋**（底部右邊的放大鏡）
- 搜尋具體事項或類別，例如「午餐」。
- 左右滑動切換日、週、月、年的範圍，看這段期間在這件事上花了多少（支出紅、收入綠）。

**時間**
- 點頂部的日期，可以直接跳到任何一天，或切換日、週、月、年。
- 週從星期一開始；有帳目的日子在月曆上有小圓點。

**其他**
- 深色模式。
- 紅綠色盲友善模式：支出改成藍色系、收入改成黃色系。
- 尊重系統的「減少動態效果」設定：開啟後行星完全靜止。
- 離線可用。

## 安裝到 iPhone

1. 用 **Safari** 開啟 <https://daystar0515.github.io/orbit-ledger/>
2. 點下方的「分享」按鈕 →「**加入主畫面**」
3. 之後從主畫面的 Orbit 圖示開啟，就會以全螢幕、像一般 App 的方式執行

## 你的資料

- 帳目只存在你手機的瀏覽器（IndexedDB）裡，**不會上傳到任何伺服器**。這個 GitHub 專案只有程式碼，沒有任何人的帳目。
- **清除 Safari 的網站資料、刪除主畫面上的 Orbit 或換手機，帳目都會消失。**
  請定期到「設定 → 備份與匯入」按「匯出備份」，並在分享選單選「儲存到檔案」。
- 備份檔（JSON）沒有加密，請存放在你信任的地方。也可以匯出 CSV 用試算表查看。
- 匯入備份不會刪除手機上現有的帳目；同一筆帳目兩邊不同時，以較晚修改的為準。

## 開發

純 HTML、CSS 與 JavaScript（ES modules），**不需要任何套件或建置步驟**，放上 GitHub Pages 就能使用。

```
index.html            頁面骨架（主畫面與各個半版視窗）
css/style.css         樣式（含深色模式、色盲模式）
js/main.js            主程式：狀態、畫面更新、操作
js/orbit.js           行星軌道視圖與各種轉場（收縮、散開、日食）
js/ring.js            省電圓環視圖
js/gestures.js        滑動與雙指縮放（即時跟手）
js/carousel.js        左右滑動選擇器
js/entry-sheet.js     記帳視窗（支出／收入／轉帳）
js/accounts.js        帳戶與餘額計算
js/asset-sheet.js     資產頁
js/search-sheet.js    搜尋頁
js/date-picker.js     日期與期間選擇器
js/reminders.js       信用卡結帳日／繳款日、存款計息日／發息日、提醒與行事曆檔（.ics）
js/adjust.js          手續費、優惠等金額調整
js/version.js         版本號
js/backup.js          備份、匯入、CSV
js/db.js              本機資料庫（IndexedDB）
js/…                  其他：類別、調色盤、明細列、設定等
tests/                單元測試
tools/make_icons.py   產生 App 圖示（需要 Python 與 Pillow）
sw.js                 Service Worker（離線可用）
```

**資料格式**

```
帳目    { id, type: 'expense'|'income', catId, accountId?, amount, date: 'YYYY-MM-DD', note, createdAt, updatedAt? }
轉帳    { id, type: 'transfer', fromId, toId, amount, date, note, createdAt, updatedAt? }
帳目    （有手續費／優惠時）多了 base: 原價、adjust: [{ k: 'fee'|'discount'|…, v }]；amount 永遠是最後的實際金額
帳戶    { id, kind: 'cash'|'credit'|'bank', name, opening,
          limit?, statementDay?, dueDay?,                                   ← 信用卡
          interestOn?, rate?, accrualDay?, payDay?, payFreq?,               ← 有設定利率的存款
          remind?: { on, offsets: [0|1|7], events: [...] } }
備份檔  { app: 'orbit', version: 3, exportedAt, count, categories, accounts, entries }
```

金額是整數（新台幣元）；日期存成字串，避免時區造成差一天。`note` 就是畫面上的「具體事項」。

**版本號**在 `js/version.js`、`package.json` 與 `sw.js` 的 `CACHE`。

**更新網站時**：改了任何檔案，記得把 `sw.js` 裡的 `CACHE` 名稱改掉（例如 `orbit-1.0.0-1`）；新增的檔案也要加進 `FILES` 清單，
否則已經安裝的手機可能還會看到舊版本。

**未來構想**：還沒開始做的想法（例如理財與「資產宇宙」）記錄在 [`docs/ROADMAP.md`](docs/ROADMAP.md)。

**測試**（需要 Node.js 22 以上）：

```
npm test
```

**重新產生圖示**：

```
python3 tools/make_icons.py icons
```
