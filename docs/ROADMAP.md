# Orbit 未來更新構想

這裡記錄已經討論過、但還沒開始做的想法，之後更新時再拿出來討論。

## 已完成：理財與資產宇宙第一期（Version 1.1.0）

- 資產宇宙（第三個宇宙）：太陽是淨資產，行星是現金、存款與理財持有；藍色系，色盲模式用薰衣草紫；軌道虛線；盈虧光環加 ▲／▼ 百分比。
- 理財大類：股票、ETF、基金；代碼、持有股數、平均成本、市價；市值、盈虧、報酬率。
- 股票與 ETF 在打開 Orbit 時自動更新市價：Cloudflare Worker（`worker/quotes-worker.js`）轉發證交所盤中即時價，
  休市或查不到時退回證交所／櫃買的每日收盤價。基金手動輸入。
- 買賣不跟存款連動（持有是獨立記錄）；資產宇宙只看現在；信用卡欠款只從太陽扣掉；只支援新台幣。

## 之後可以做（尚未開始）

1. **買進／賣出／股利與存款連動**
   - 買進＝「存款 → 持有」的轉帳（含手續費），賣出反向，股利記為收入。
   - 要處理手續費與證交稅（台股一般 0.3%、ETF 0.1%）。
   - 連動後，支出類別裡的「投資」就不該再用來記買股票，以免重複。
   - 也要決定同一檔股票多次買進時，平均成本怎麼算。
2. **資產的歷史變化**：目前只看現在。要看某段期間的資產變化，需要保存歷史市價。
3. **信用卡欠款的呈現**：目前只從太陽扣掉；也可以做成暗色的「黑洞」或小行星帶。
4. **外幣計價**（美股、海外基金）：需要匯率。
5. **基金淨值自動更新**：目前沒有穩定的免費來源，之後可以再查證。
6. **漲跌顏色**：目前賺是綠色、賠是紅色（和支出紅、收入綠一致）。台股習慣漲紅跌綠，若覺得混淆，可以加一個「漲跌顏色」設定。
7. **上架 App Store**：評估過，目前先不上架。需要 Apple Developer Program（US$99／年）、Capacitor 包裝、雲端 Mac 或 CI 建置；
   審核要避開指南 4.2（網站包裝），建議加上原生本機通知。

## 報價服務的備註

- 瀏覽器無法直接讀取證交所、櫃買、Yahoo 財經（皆被 CORS 擋下，已在手機上實測），所以需要轉發。
- Worker 只會收到股票代碼；只接受來自 Orbit 網站的瀏覽器請求，一次最多 30 檔。
- 證交所盤中介面（mis）是網站內部使用的，沒有正式承諾；Worker 已經用官方開放資料做備援。
