# Orbit 未來更新構想

這裡記錄已經討論過、但還沒開始做的想法，之後更新時再拿出來討論。

## 理財與「資產宇宙」（2026-10-10 討論，暫緩）

### 想法

- 資產頁新增一個大類「理財」，預設子類有**股票、ETF、基金**。
- 每一筆持有輸入：代碼、持有數量（股數／單位數）、持有均價、當下市價 → 計算**目前市值**與**盈虧**。
- 依照 Orbit 的宇宙呈現，新增**第三個宇宙「資產」**（支出、收入之外）：
  太陽是總資產，現金、存款與各個理財持有都是行星，大小代表價值。
- 盈虧的視覺：賺錢的行星外圍是綠色光環、虧錢的是紅色光環，光環越亮代表報酬率越高（色盲模式改成藍／黃）。
- 切換方式：上下滑變成三個宇宙循環（支出 → 收入 → 資產），頂部切換鈕變三格，沿用日食轉場。

### 開始前要先決定的問題

1. **市價從哪裡來**
   - 手動輸入：最簡單可靠，畫面顯示「市價更新於某日」。
   - 自動抓價：Orbit 沒有伺服器，只能用允許網頁直接存取的免費報價服務；需要金鑰的服務不適合（會公開在 GitHub 上）。
     台股、美股、基金的可用來源要實際查證後才能決定。
   - 建議：第一版手動，之後再研究自動。
2. **買股票的錢要不要跟存款連動**
   - 簡單版：理財持有獨立記錄，存款不會減少（淨資產會重複計算）。
   - 完整版：買進＝「存款 → 持有」的轉帳（含手續費），賣出反向，股利記為收入；需要處理手續費與證交稅（台股一般 0.3%、ETF 0.1%）。
   - 連動的話，支出類別裡的「投資」就不該再用來記買股票，以免重複。
3. **資產宇宙的日／週／月／年是什麼意思**
   - A：只看「現在」，縮放手勢在資產宇宙停用（建議先做這個）。
   - B：顯示這段期間的資產變化，需要保存歷史市價，複雜很多。
4. **信用卡欠款怎麼呈現**：只在太陽的淨資產裡扣掉；或做成暗色的「黑洞」／小行星帶。
5. **小數**：股價、零股、基金單位數有小數，這些欄位要支援小數，市值再四捨五入成新台幣整數；
   外幣計價（美股、海外基金）需要匯率，建議第一版只支援新台幣。

### 建議分期

1. 理財大類（手動市價、市值與盈虧）＋資產宇宙（只看現在）＋盈虧光環。
2. 買進／賣出／股利與存款連動，含手續費與證交稅。
3. 自動更新市價；資產的歷史變化。
